# Keyan Lu Portfolio

A dependency-free personal portfolio prepared for GitHub Pages.

## Preview

Open `index.html` directly in a browser. No build step is required.

## Publish with GitHub Pages

1. Create a repository named `Keyan-col.github.io` or use an existing Pages repository.
2. Upload the contents of this directory to the repository root.
3. In GitHub repository settings, enable Pages from the default branch and root directory.

## Add a project

Duplicate one `.project-card` block in `index.html`. Set `data-category` to one or more of `research`, `data`, and `engineering` so the filter works automatically.
